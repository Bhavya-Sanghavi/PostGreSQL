Q4.1 

EXPLAIN SELECT *
FROM employees e
JOIN departments d 
ON e.department_id = d.id;

"Hash Join  (cost=1.14..15.60 rows=6 width=464)"					uses a hash based algorithm to join the two tables
"  Hash Cond: (d.id = e.department_id)"               					condition used for joining
"  ->  Seq Scan on departments d  (cost=0.00..13.20 rows=320 width=222)"        	reads the table sequentially
"  ->  Hash  (cost=1.06..1.06 rows=6 width=242)"                			estimated startup cost and total cost
"        ->  Seq Scan on employees e  (cost=0.00..1.06 rows=6 width=242)"		estimated number of rows and average size of each output row in bytes



Q4.2

EXPLAIN SELECT e.*, d.*
FROM employees e,
(SELECT * FROM departments) d
WHERE e.department_id = d.id;

"Hash Join  (cost=1.14..15.60 rows=6 width=464)"
"  Hash Cond: (departments.id = e.department_id)"
"  ->  Seq Scan on departments  (cost=0.00..13.20 rows=320 width=222)"
"  ->  Hash  (cost=1.06..1.06 rows=6 width=242)"
"        ->  Seq Scan on employees e  (cost=0.00..1.06 rows=6 width=242)"
